# Portafolio, cómo editarlo y publicarlo

Todo lo que hay que cambiar está marcado con comentarios `EDITAR` o con el texto `[Completar]` dentro de `index.html`.

## Editar
1. Abre `index.html` en VS Code.
2. Cambia los textos y enlaces. Para un proyecto nuevo, copia un bloque `<article class="card">` completo.
3. Pon tus fotos en la carpeta `assets/` con los nombres que ya usa el HTML, o cambia los nombres en el HTML.
4. Para verlo local, abre `index.html` con doble clic.

## Publicar en GitHub Pages
1. Crea en GitHub un repo público llamado exactamente `PabloJLM.github.io`.
2. Sube el contenido de esta carpeta (index.html, style.css, assets).
3. En el repo, ve a Settings, luego Pages, y elige la rama `main` y la carpeta `/ (root)`.
4. En uno o dos minutos queda en https://pablojlm.github.io

Optimiza las fotos antes de subirlas, de preferencia menos de 300 KB cada una.
